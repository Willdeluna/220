🧠

Core Concept — What ATA 22 Really Does

ATA 22 does not directly move the airplane→It commands the flight control system to move the surfaces.
Auto flight is a logic system→Think data, modes, and computers before replacing autopilot parts.big takeaway
Wrong behavior usually means wrong data or wrong mode→The autopilot may be following bad guidance perfectly.
🧩

System Architecture

DMCs are the thinking layer→They combine FMS, navigation, and air data to build the flight path solution.
PFCCs are the execution layer→They convert commands into flight-control movement.memory hook
Three PFCCs use majority-vote logic→One disagreement can be ignored, so the system usually degrades instead of quitting.
✈️

Flight Guidance System

FGS decides what the airplane should do→Climb, descend, turn, hold speed, intercept, or capture.
Autopilot follows FGS commands→Bad guidance can create bad-looking aircraft behavior with a good autopilot.
Every movement is lateral or vertical→Lateral: HDG, LNAV, LOC. Vertical: VNAV, ALT, VS, GS.easy sorting
📺

FMA — Flight Mode Annunciator

FMA shows the real active system state→Do not troubleshoot based only on what mode was selected.FMA is truth
FMA separates lateral, vertical, and autothrottle modes→It tells you which part of the logic is actually active.
Mode reversion is normal protection logic→If conditions are not met, the system may switch modes automatically.
🕹️

Autopilot — What It Actually Does

Autopilot works through FBW laws→It does not bypass flight-envelope protections.
Normal Law protections still apply→The autopilot is limited by system laws and cannot command unsafe behavior.
Engagement needs stable, clean signals→Conflicting inputs or invalid data can cause immediate disconnect.line MX clue
⚠️

Autopilot Disconnect Logic

Disconnect usually equals protection→Do not instantly call it an autopilot failure.important
Common triggers: sensor disagreement or envelope exceedance→Invalid inputs make the system back out.
Sidestick conflict or trim mismatch can drop AP→Check aircraft state and pilot input paths before blaming the AP.
⚡

Autothrottle / ATS

ATS manages energy→It controls the speed and thrust relationship, not just throttle position.
THRUST mode fixes power, SPEED mode chases speed→Know which mode is active before calling the response wrong.
ATS faults can be physical→Servo, linkage, and throttle quadrant issues are real moving-part problems.unlike AP
🛬

Autoland

Autoland uses many systems at once→ILS, radio altimeter, IRS, and air data all matter.
Phases: APP, FLARE, ROLLOUT→Alignment, flare around low altitude, then centerline control.
LAND3, LAND2, NO LAND = integrity levels→The system downgrades when redundancy is reduced.degrades gracefully
🚨

Emergency Descent Mode

EDM can activate automatically→Unsafe cabin altitude can trigger a safety response.
System engages AP and AT logic→It commands idle thrust and descent to protect occupants.
Not every dramatic action is a fault→EDM is designed safety behavior, not random airplane weirdness.A220 feature
📡

Sensor Dependency

ATA 22 depends heavily on IRU, ADC, and GPS→Position, attitude, speed, altitude, and navigation data drive the system.
Sensor disagreement causes degradation or disconnect→If the computers cannot trust the data, they limit the function.
Most ATA 22 issues are input-data issues→Bad input data makes good logic behave badly.root cause clue
🎚️

Mode Logic

Managed mode = FMS controlled→The aircraft follows computed flight plan logic.
Selected mode = pilot/FCP controlled→The crew-selected value controls the target.
Blank FCP window can be normal→Managed mode may hide selected targets because the FMS is driving.don’t overthink it
🔧

Troubleshooting Mindset

Start with FMA→Confirm the mode that is actually active.
Check inputs before computers→Validate airspeed, altitude, IRS, GPS, and sensor status.
Use BITE and fault history→Look for PFCC/DMC faults and mode reversion clues.best order
🔗

System Interaction — Why Problems Spread

ATA 22 depends on ATA 34 navigation→Bad nav/air data can show up as auto flight problems.
ATA 22 depends on ATA 31 displays→The FMA and display indications are your troubleshooting window.
ATA 22 depends on ATA 27 flight controls and ATA 24 electrical→Execution and power problems can look like autopilot issues.someone else’s problem
