Core Concept — What ATA 26 Really Is

Centralized detection + protection system→ATA 26 detects fire, smoke, and overheat, then alerts and protects the airplane.
Protect first, alert second→The system is designed to prevent damage and isolate hazards, not just light up messages.big idea
Sensors → FIDEX → logic → action→Follow the logic path before blaming hardware.
🧩

FIDEX — System Brain

FIDEX controls ATA 26→It monitors loops, smoke detectors, bottles, pressure, panels, and system outputs.
Dual-channel and self-monitoring→Separate channels and power sources keep protection available after many failures.redundancy
Sends data to EICAS and OMS→CAS messages are clues to where the logic found the issue.
🔁

Dual-Loop Logic — The Key

Normal mode uses AND logic→Both loops usually need to agree before a fire warning is triggered.
Single loop failure can switch to OR logic→Protection remains, but the decision logic changes.testable
Both loops failed = detection lost→That becomes a caution and changes what protection is available.
📍

Detection Areas

Fire / overheat zones→Engines, APU, and main wheel well are monitored for heat conditions.
Smoke detection zones→Cargo compartments, equipment bays, avionics areas, and lavatories use smoke detection.
Different zone = different sensor type→Don’t troubleshoot a smoke detector like a fire loop.
🌡️

Detection Physics

Fire loops sense temperature change→Heat changes loop resistance and the system interprets the condition.
System separates fire from electrical shorts→Rate-of-change logic helps prevent false warnings.
Loops detect overheat, open, and short→Loop faults are common write-ups, not automatic fire events.MX clue
✈️

Engine Fire Protection

Dual loops monitor each engine→Normal logic prevents false warnings by requiring confirmation.
FIRE PBA isolates the engine→Fuel, bleed, hydraulics, generator, and FADEC shutdown actions are commanded.isolation
BTL PBA discharges the bottle→Fire button isolates; bottle button releases extinguishing agent.
🧯

Bottle System

Engine/APU bottles use Halon 1301→Nitrogen pressure drives agent discharge.
Pressure switches are continuously monitored→Low pressure can create bottle fault indications.
Green available = ready→Amber or low indications point toward pressure or bottle faults.
⚙️

APU Fire Logic

APU uses dual-loop detection→Like engine detection, but with its own extinguishing bottle.
Ground fire can auto-shutdown→On the ground, the system can shut down the APU automatically.
Auto-discharge after timer→If no crew action occurs, a ground APU fire may command automatic discharge.unique feature
📦

Cargo Fire System

Cargo uses smoke detection→This is not a heat loop system.
Timer confirmation logic matters→One detector can start a timer; confirmation may require another detector.logic-based
Ventilation shuts off during cargo fire→ATA 21 interaction helps contain smoke and agent concentration.
⏱️

Cargo Extinguishing

HRD bottle knocks the fire down fast→High-rate discharge gives quick initial suppression.
LRD bottle prevents re-ignition→Low-rate discharge maintains agent concentration over time.
Suppression is time-based→The goal is sustained concentration, not just a quick blast.
🚻

Lavatory & Smoke Detection

Lav has detector plus automatic extinguisher→The extinguisher releases automatically when heat melts the plug.
Dual-wavelength optical detection→Smoke and dust are separated better to reduce false alarms.smart detector
Detectors self-monitor and degrade→Contamination or calibration drift may show up before total failure.
🔧

BITE, CAS & Troubleshooting

Run FIDEX test early→Tests check loops, detectors, FIDEX, bottles, and panels.
CAS tells you where to start→FIRE, DET FAIL, BTL LOW, and SYSTEM FAULT point to the affected area.
Most faults are sensors, not fires→Loop faults, detector contamination, pressure switches, and cartridges are common.line MX
