Core Concept — FBW + Electrohydraulic

A220 flight controls are fly-by-wire→Pilot inputs are not mechanical; sidestick commands go through computers before surfaces move.
Computers command hydraulics→You are troubleshooting a computing system controlling hydraulic actuators, not cables and linkages.big idea
System interprets pilot intent→The system adds protections and then moves surfaces electronically.
🧩

System Breakdown

Primary controls→Ailerons, elevators, and rudder control the main flight axes.
Secondary controls→Spoilers and stabilizer support roll, lift dump, speed brake, and pitch trim.structure
High lift is separate→Flaps and slats are non-EFCS and use SFECUs plus mechanical/hydraulic components.
🔁

Fly-By-Wire Logic

Pilot commands aircraft response→The pilot is not directly commanding surface position; the system targets aircraft behavior.
Dual-loop control→Inner loop commands actuators; outer loop checks aircraft response feedback.logic
Constant correction→The system keeps adjusting to match pilot intent and aircraft conditions.
🧠

EFCS Architecture

Easy flow→Sidestick → IIM → PFCC → REU → PCU → surface.
Multiple control paths→Three independent paths plus backup give strong redundancy.flow
Each box has a job→Input, compute, command, actuate, then verify surface response.
💻

PFCC — Main Flight Control Computer

Three PFCCs total→One active and two standby provide layered redundancy.
Command and monitor lanes→If the lanes disagree, output can be blocked to prevent bad commands.protection
PFCC protects against bad data→It is not just a computer; it is a safety gate for control commands.
⚠️

Control Modes / Degradation

Normal Mode→Full augmentation, autopilot, and envelope protection available.
Direct modes reduce features→PFCC Direct, REU Direct, and AFCU Direct progressively remove automation and protection.key MX item
System degrades step-by-step→Expect degraded modes, not instant total flight-control failure.
🛡️

Envelope Protection

Normal mode protects the airplane→The system helps prevent stall, overspeed, excessive pitch/roll, and structural overload.
Limits are built into laws→Pitch and load limits help keep the aircraft inside the safe envelope.FBW advantage
Autopilot and pilot inputs stay under protections→In normal mode, the airplane filters commands through flight-control laws.
🎛️

Inceptors / Pilot Inputs

Sidesticks use sensors→RVDTs sense stick position; pilot feel is artificial, not aerodynamic.
No physical link between sticks→Dual inputs can create warnings and priority logic.common write-up
Priority button matters→One pilot can take control and override the other sidestick.
💧

Hydraulic Actuation

PCU converts signal to movement→Electrical commands become hydraulic surface motion.
PCU states matter→Active, soft damped, and hard damped states prevent fighting and protect structure.MX clue
Do not blame the actuator first→Bad data or control logic can look like actuator trouble.
🪽

Ailerons / Roll Control

Two ailerons total→One per wing, each with two active-active PCUs.
More than roll→Ailerons can also move symmetrically for lift assist.bonus
Landing lift dump help→Ailerons can support lift dump logic during landing.
⬆️

Elevators / Pitch Control

Two elevators move symmetrically→Pitch movement comes from elevator surfaces commanded through EFCS.
No elevator trim→Pitch trim is handled by the horizontal stabilizer, not the elevators.don’t chase wrong part
Pitch trim issue = stabilizer area→Check HSTA/MCE logic before chasing elevator trim that does not exist.
↔️

Rudder / Yaw Control

Triple PCU redundancy→Three PCUs power the rudder, each tied to different hydraulic supply logic.
Can degrade to single PCU→The system remains controllable after failures.reliability
Yaw control is heavily protected→Triple redundancy makes full rudder loss unlikely.
⚙️

Horizontal Stabilizer Trim

HSTA is electric→Stabilizer trim uses an electric actuator, not hydraulic PCUs.
Two motors→Active and standby motor logic provides backup control.critical
Runaway protection→No-back device, electric brake, and logic protect against runaway trim.
🪶

Spoilers

Multifunction spoilers→Spoilers provide roll assist, lift dump, and speed brake functions.
Logic-driven deployment→WOW, thrust, airspeed, and radio altitude can all affect spoiler operation.condition-based
Degraded mode clue→Loss of auto ground deployment can point to mode or input logic.
🛬

Ground Spoilers

Auto deploy on landing→Ground spoilers require multiple conditions such as WOW, speed, and thrust.
No deploy? Check logic first→Missing one input can stop deployment even if hardware is good.line MX
Manual may remain available→Some degraded conditions remove automatic deployment but leave manual function.
🛫

High Lift System

Slats/flaps are separate→Controlled by SFECUs, not PFCCs.
Mechanical + electronic hybrid→Hydraulic power moves gearboxes, torque shafts, and actuators.sequence
Extend slats first, retract flaps first→Sequence logic matters during abnormal operation.
🔎

High Lift Monitoring

System watches position and motion→Skew, asymmetry, speed, and position are monitored continuously.
Mismatch = shutdown→The system stops movement to prevent structural damage.protection
Fault may be protection logic→A shutdown can be the system doing exactly what it should do.
⚡

Power & Redundancy

FBW power is protected→FBWPC, DC ESS, and PMAG backup keep controls powered.
Three hydraulic systems→Different surfaces use different supplies for redundancy.survival system
Controls should not lose power easily→Electrical and hydraulic backup is central to ATA 27 design.
📺

Indications & Testing

Use synoptic and EICAS→Surface position, status, trim, and warnings guide troubleshooting.
Amber and amber X matter→Failed versus invalid indications point to different fault paths.BITE
OMS tests before parts→ABIT, IBIT, and PBIT can test surfaces, shaker, and actuators.
🔧

Maintenance Reality

Most faults are data-driven→RVDT/LVDT sensors, PFCC/REU logic, and data mismatch are common.
PCU failure is less common→Do not start with the parts cannon.best practice
Follow Data → Logic → Actuator → Surface→That order solves most ATA 27 write-ups.
