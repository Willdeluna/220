CORE Concept (Most Important Idea)

ATA 36 = central air supply system for the aircraft→Provides high‑pressure, high‑temperature airkey
Feeds→Packs (ATA 21) Wing/engine anti‑ice (ATA 30) Fuel tank inerting (ATA 47) Engine start If bleed air fails → multiple systems go down (ECS, anti‑ice, start)

System Architecture (Big Picture)

Two independent sides (L/R)→→ Normally isolated Cross‑Bleed Valve (CBV) connects both sides when needed Big concept: Split system normally, interconnected when required
Controlled by→IASCs (Integrated Air System Controllers) Same controllers as ATA 21 → strong integration ⚙️ 3. Bleed Air Sources (Core Concept)
Three sources→Engine bleed APU bleed External air 🔥 Engine Bleed (Primary Source)
Taken from→4th stage (normal) 8th stage (high demand)
Easy→Low demand → 4th stage High demand → 8th stage Switching controlled automatically by HPV (High Pressure Valve) ⚠️ APU Bleed (Ground + Backup) Default source on ground

IASC (SYSTEM BRAIN – MOST IMPORTANT)

Controls→Valves Pressure Temperature Source selection
Has→Channel A (primary) Channel B (backup) Channel C (safety monitoring) 🔥 Huge concept: System decisions = IASC logic, not pilot input ⚠️ 5. Pressure Control (KEY SYSTEM) Controlled by PRSOV (Pressure Regulating Shutoff Valve) Maintains pressure ≈ 41.5 psi → optimized for pack performance
Can→Regulate pressure Shut off flow Key: PRSOV = main control + protection valve ⚠️ 6. High Pressure Valve (HPV)
Controls switching between→4th stage ↔ 8th stage
Opens when→Pressure too low Temperature insufficient Important: HPV is fully automatic 🌡️ 7. Temperature Control (Very Important) Bleed air is extremely hot (~200–500°C)

BALODS (Leak Detection System – VERY IMPORTANT)

Detects→Bleed leaks Overheatkey
Uses→Dual detection loops Big concept: Protects aircraft structure from hot leaks ⚠️ 16. Leak Detection Logic Normal: → BOTH loops must detect Degraded: → single loop Failure: → shutdown affected zone Same AND/OR logic concept as fire system ⚠️ 17. Automatic Protection Actions
System may close→PRSOV CBV Pack valves Anti‑ice valves APU bleed valve Huge takeaway: Bleed leak affects MULTIPLE systems instantly ⚠️ 18. Leak Zones (High-Level Understanding)
